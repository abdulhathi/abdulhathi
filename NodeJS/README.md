# Node.js

Learning Node.js with TypeScript, from beginner to advanced.

| Folder | What it is |
|---|---|
| [`tutorial-app/`](tutorial-app/) | The course: a React app with 20 chapters, 11 practice projects and reference appendices |
| `projects/` | My own work, one folder per chapter project (`01-hello-node`, `02-modules-lab`, …), built by following the course |

Run the course:

```bash
cd tutorial-app
npm install
npm run dev
```
