# DSA

Data structures and algorithms study, technique by technique.

- `tutorial-app/` is the **DSA Lab**: run `npm install && npm run dev` inside it and open the URL it prints.
- Keep your own accepted LeetCode solutions in `solutions/`, one folder per chapter (for example `solutions/two-pointers/0011-container-with-most-water.ts`), each with a comment at the top stating the key idea in your own words.
